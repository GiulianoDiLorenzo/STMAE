Purpose of the project:

Instrument classification and labeling. First, be able to classify individual instrument audios (stems) and then be able to label the different instrument presents in a track.

Data extraction:

The idea is to use MedleyDB to build our own data set. In our data set, we will found audios of 3 seconds from both Stems and MIX.

For Stems, we look for the activations and only save audio when the instrument it's active. We save the stems on a folder with all the stems that are the same instrument

For the MIX, we use the information about activations to look for itervals with no no activations or desactivations. This way, the audios we extract have during all their lenght the same instruments active. 

In both cases, audios are taken with 50% overlap to have a bigger dataset. 

Once this is done, we compute and save the mel-espetrogram and the CQT, both with 96 frequency bins. This leads to matrices of 96 * 130.

Regarding the labels, there are 82 different instruments in the original dataset. What we do is eliminate some of them and create groups or classes with others, to balance a little bit more the data and reduce the amount of classes. We end up with 18 classes explained in this list:

First it's we have to considera batchnormalization. This it's not the model layer called batch, this means before giving the spectrograms to the model, we normalize the ones belonging to the same batch (usually 32) to have average 0 and std 1. 

Something like the following pseudocode (reask chat gpt):

def normalize_batch(x, y):
    mean = tf.reduce_mean(x)
    std = tf.math.reduce_std(x)
    return (x - mean) / std, y

For the first two models, we can try different models that goes better for each problem, but when doing the hybrid problem, we need to find a model that it's good clasiffying both (something in the middle). We can use the models in the pappers. One propposed for stem classification: (not use directly, i didn't ask even what it does, it's just to have an overall idea)

Another proposed by carmen is in ModelforMix. 

Conv2d, maxpooling and dropout are very important. Even more in the hybrid, because we want the fit to the stems to be consistent and without overfitting, because we later need to train with MIX.

When changing from stems to mix in the hybrid, change from softmax (useful for 1 activation) to sigmoid (useful for mutilarle).

Example of hybrid model:

# Fase 1: Model for stems
model_phase1 = models.Sequential([
    layers.Input(shape=(128, 96, 1)),
    layers.Conv2D(32, kernel_size=(5, 5), activation='relu', name='conv1'),
    layers.MaxPooling2D(pool_size=(5, 3)),
    layers.Conv2D(32, kernel_size=(5, 5), activation='relu', name='conv2'),
    layers.MaxPooling2D(pool_size=(5, 3)),
    layers.Flatten(),
    layers.Dense(64, activation='relu', name='dense1'),
    layers.Dropout(0.5),
    layers.Dense(num_instruments, activation='softmax', name='output')  # Softmax para single-label
])

# Train 1 with stems
model_phase1.compile(optimizer='adam',
                    loss='sparse_categorical_crossentropy',
                    metrics=['accuracy'])
model_phase1.fit(stems_dataset, epochs=100)

# Fase 2: Multilable
# Crear un nuevo modelo reutilizando las capas entrenadas
inputs = layers.Input(shape=(128, 96, 1))
x = model_phase1.get_layer('conv1')(inputs)
x = model_phase1.get_layer('pool1')(x)
x = model_phase1.get_layer('conv2')(x)
x = model_phase1.get_layer('pool2')(x)
x = layers.Flatten()(x)
x = model_phase1.get_layer('dense1')(x)
x = layers.Dropout(0.5)(x)
# Cambiar a activación sigmoide para multi-etiqueta
outputs = layers.Dense(num_instruments, activation='sigmoid', name='output')(x)
